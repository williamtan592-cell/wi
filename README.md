# Willy. Co portfolio

Plain HTML and CSS. No build step.

## Files
- `index.html`: all content
- `style.css`: styling (colours are in the `:root` block)
- `photo.jpg`: portrait used in the hero and contact sections

## Deploy with GitHub and Netlify
1. Create a GitHub repository and upload all four files to the root.
2. In Netlify, choose **Add new site → Import an existing project → GitHub** and pick the repository.
3. Leave the build command empty and the publish directory blank (or `/`).
4. Click **Deploy**. Every push to GitHub redeploys the site.
